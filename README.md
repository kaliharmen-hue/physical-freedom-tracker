# Physical Freedom Tracker

A local-first training, capacity and symptom-response tracker designed around one principle: **build capacity, don't just track pain**.

## Current status

V0.1 specification started.

The first programmed session is a home lower-body test/build workout designed to preserve meaningful strength and hypertrophy training while learning which loading patterns are currently well tolerated.

See [`PROJECT_SPEC.md`](PROJECT_SPEC.md) for the working specification.

## V0.1

The first usable build will include:

- Today dashboard
- Morning symptom check
- 15-minute daily capacity routine
- Programmed workouts
- Set/load/reps logging
- Exercise-specific symptom response
- Next-morning response
- History
- Local persistence

## Technical direction

React + TypeScript + Vite, initially local-first, with GitHub Pages as the intended deployment target.
